# VIMO v3

Apresentação oficial com simulador local. Hospedagem principal: https://vimooficial.netlify.app/ . Código em vimo/ no repositório 7tpn72gd7b-byte/cj.

## Executar

`python3 -m http.server 8080` nesta pasta.

## Publicar

No Netlify, diretório-base vimo, publicação ., sem build. A distribuição manual contém index.html na raiz. O contato é configurado em assets/config.js; o proprietário autorizou publicar esse número no repositório público.

## Mídias e demonstração

Retratos, eventos e vídeo são ilustrativos. As novas fotografias foram geradas para o projeto. O vídeo MP4 é uma animação de fotografia ilustrativa. Fotos/vídeos escolhidos pelo visitante ficam somente na sessão local. Limite por arquivo: 100 MB. Recursos reais e condições comerciais dependem de proposta.
